# FitLog — Workout Library

FitLog is a dark, responsive workout library and planning web application. Users can explore workouts, view detailed workout information, add exercises to today's plan, save workouts for later, and manage their workout plan.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Next.js App Router
- REST API
- LocalStorage

## Key Features

- Browse 12 workouts from the FitLog API.
- View detailed information, equipment, difficulty, sets, reps, duration, calories, and rating for each workout.
- Add workouts to today's plan with a maximum limit of five exercises.
- Save workouts for later and manage saved exercises.
- Track total exercises, workout minutes, and calories in My Plan.
- Sort workouts by duration, calories, or rating.
- Mark planned workouts as done or remove them from the plan.
- Responsive design for mobile, tablet, and desktop.
- LocalStorage persistence for today's plan and saved workouts.

## Project Structure

- `app/` — Pages and routes
- `components/` — Reusable UI components
- `context/` — FitLog state management
- `lib/` — API functions
- `public/` — Logo and banner assets
